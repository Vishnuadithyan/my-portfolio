# Vishnu Adithyan — Personal Portfolio

Personal portfolio website built with React, Vite, and Tailwind CSS.

## Scripts

- `npm run dev` — Start local development server
- `npm run build` — Build production bundle to `dist/`
- `npm run preview` — Preview production build locally
- `npm run lint` — Run ESLint across the codebase

## Customization

Edit `src/data/portfolioData.js` to update your email, social links, skills, work experience, and project links.
GitHub, LinkedIn, and project repository/live links render automatically once replaced with valid non-placeholder URLs.
